# Curso_Node

Ejercicios y proyectos del curso **Node.js de cero a experto**. Cada carpeta es un módulo independiente con su propio `README.md` y, cuando aplica, su propio `package.json`.

## Módulos

| Carpeta                                        | Descripción                                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [01-hola-mundo](01-hola-mundo)                 | Primeros pasos con Node.js: scripts sueltos para practicar sintaxis básica de JavaScript.        |
| [02-Fundamentos](02-Fundamentos)               | Fundamentos de JavaScript moderno (callbacks, promesas, async/await, desestructuración, etc.).   |
| [03-bases-node](03-bases-node)                 | CLI que genera tablas de multiplicar y las guarda en archivo `.txt`.                              |
| [04-tareas-hacer](04-tareas-hacer)             | To-Do List de consola con persistencia en JSON y salida coloreada.                                |
| [05-clima-app](05-clima-app)                   | CLI de clima: geocodificación con Mapbox + clima actual con OpenWeatherMap, con historial en JSON.|
| [06-webserver](06-webserver)                   | Servidor Express con plantillas Handlebars y archivos estáticos.                                  |
| [07-restserver](07-restserver)                 | API REST con Express + MongoDB (Mongoose), JWT, Google Sign-In, roles, CRUD y carga de imágenes.  |
| [08-websocket-server](08-websocket-server)     | Servidor Express + Socket.io para comunicación en tiempo real.                                    |
| [09-socket-colas](09-socket-colas)             | Sistema de turnos/tickets en tiempo real con Express y Socket.io.                                  |
| [10-socket-chat](10-socket-chat)               | API REST (Express + MongoDB) con autenticación JWT/Google y chat en tiempo real con Socket.IO.    |
| [11-ts-restserver](11-ts-restserver)           | API REST con Express, TypeScript y Sequelize (PostgreSQL).                                        |

## Uso

Cada módulo se instala y ejecuta de forma independiente. Entrar a la carpeta correspondiente y seguir las instrucciones de su propio `README.md` (generalmente `npm install` y luego el script de arranque indicado).
